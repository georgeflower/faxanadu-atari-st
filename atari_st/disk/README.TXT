FAXANADU FOR THE ATARI ST
Europe NES game, 520 STFM, 68000 asm.
Data made from the author's own ROM:
keep the disk to yourself.

NEEDS: 512 KB, colour, low res, PAL.
Keep this disk in the drive: the areas
load from it. Boot from it: the game
is in the AUTO folder and starts by
itself (or run AUTO\FAXANADU.PRG).

TITLE: Up/Down/Tab pick, fire/Return
confirm. START begins the game.
CONTINUE loads SAVE.SAV or takes a
mantra.

SAVING: a Guru asks: Save to disk or
Show mantra (fire or Space takes, Alt =
mantra). SAVE.SAV is the mantra as text
on this disk, which must not be write
protected (a Gotek image must be
writable).

KEYS: stick Up jumps, climbs, enters
doors and talks. Left, Right, Down as
usual. Fire or Alt: sword, Down+Fire
item. Space: spell. Arrow keys = the
stick. Tab: player menu. Return:
pause. Esc: save or quit. T: trainer
(no damage, area and screen shown).
In menus fire or Space choose, Alt goes
back.

Not as in the game: the timing of the
intro, the ending and the fades is
approximate.
